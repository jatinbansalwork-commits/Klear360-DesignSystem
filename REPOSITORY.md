# Repository — Single Source of Truth

There is **one** GitHub repository for this monorepo.

| | |
|---|---|
| **Canonical name** | `Klearnow.ai` |
| **Browse / clone** | https://github.com/jatinbansalwork-commits/Klearnow.ai |
| **SSH** | `git@github.com:jatinbansalwork-commits/Klearnow.ai.git` |
| **HTTPS** | `https://github.com/jatinbansalwork-commits/Klearnow.ai.git` |

```sh
git clone https://github.com/jatinbansalwork-commits/Klearnow.ai.git
```

## Do not use the old URL

`https://github.com/jatinbansalwork-commits/Klear360` is a **redirect** to `Klearnow.ai`.  
There is no second repository — update bookmarks, remotes, and docs to `Klearnow.ai` only.

```sh
# Fix an existing clone still pointing at the old remote
git remote set-url origin https://github.com/jatinbansalwork-commits/Klearnow.ai.git
```

## Names (not the same thing)

| Name | What it is |
|------|------------|
| **Klearnow.ai** | GitHub repo (this monorepo) |
| **Klear360** | Design system product name (`@klear/klear360` package) |
| **Local folder `Klear360`** | Your machine's directory name — can differ from the repo name |
